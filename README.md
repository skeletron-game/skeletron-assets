# Getting Started:
__How to start:__  
- Clone codebase repo: `git clone https://codeberg.org/bhorolsky/skeletron.git && cd skeletron` or from [github.com](https://github.com/bhorolsky/skeletron.git)  
- Clone this assets repo: `git clone --depth=1 https://codeberg.org/bhorolsky/skeletron-assets.git && cd skeletron-assets` or from [github.com](https://github.com/bhorolsky/skeletron-assets.git)  
- Move assets to codebase directory: mv ./skeletron-assets ./skeletron
